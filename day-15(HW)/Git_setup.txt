Q1. What happens when you run git status before git init?

It throws an error:

fatal: not a git repository

👉 Meaning:
Git cannot track anything because the folder is not initialized.

Q2. What does U, A, M mean?
U (Untracked)
→ File exists but Git is not tracking it
A (Added)
→ File is staged and ready for commit
M (Modified)
→ File was already committed before, but now changed

👉 When does M appear?

After you edit a file that was already committed
Then run git status
Q3. Git workflow in 3 steps

If you don’t understand this, you don’t understand Git. Period.

Create / Modify files
→ working directory
Stage changes (git add)
→ tell Git what to include
Commit (git commit)
→ save snapshot permanently
